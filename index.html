本机草稿和网站发布有什么区别？

本机草稿保存在当前浏览器，其他设备和访客看不到；清理浏览器数据可能会丢失。发布会把素材保存到你的 luna 仓库，更新后所有设备都能看到。

首次发布需连接有 luna 仓库 Contents 读写权限的 GitHub fine-grained token。连接信息只用于当前页面，不保存到浏览器。不要在聊天中发送 token。

也可在 GitHub 上传文件

将待发布的系列与素材保存到 ashlandkrug878-wq/luna，公开展示。
