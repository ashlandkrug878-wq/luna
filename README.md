# Luna

Luna 的系列作品网站。当前已上线基础形象、角色设计规范和自主上传入口。大牌九图、产品图与视频将分批补充。

点击网站右上角“添加作品”可保存本机草稿；发布到仓库需提供仅本页临时使用的GitHub凭证，授予luna仓库Contents读写权限。凭证不会保存到本机或仓库。

网站地址：https://ashlandkrug878-wq.github.io/luna/

## 当前角色设定

**努力羞耻：明明费尽全力，却要显得毫不费力。**

她很在意，但总想表现得若无其事。保持娇俏，用视线和小动作透露在意。

双辫与眼镜的造型可以变化；宽眼距、单眼皮、高额头与雀斑保留。身体比例沿用用户指定的奢侈品系列参考图，不自行重设头身比。

当前设定依据：[Luna 角色设计规范 v1.1](Luna_Character_Design_Guide_v1.md)。文件名保留不变，版本以正文为准。网站角色档案直接读取该文件。
